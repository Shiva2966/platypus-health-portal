## Incident note
During the production test, PowerShell `$env:X=''` *deletes* a variable, so `.env`'s real SMTP settings were loaded. The production test instance (port 8012) probably sent **one** sign-up code email via Gmail to the undeliverable address `prod.<random>@example.test`; expect a bounce in the sender inbox. No other email could be sent (that DB had no accounts for login/reset). Every later instance pinned SMTP to a dead local port.
